# Tournaments App

Тестовое задание на позицию Fullstack Developer.

## Просмотр
https://tournaments-app-xi.vercel.app/

## Описание

Реализован виджет расписания пробных тренировок в формате турнирного расписания.

## Стек

- React 19
- TypeScript
- Vite
- SCSS
- Feature-Sliced Design (FSD)

## Возможности

- Отображение списка тренировок
- Карточки тренировок
- Информация о тренере
- Отображение даты
- Информация о свободных местах
- Адаптивная верстка

## Запуск проекта

```bash
npm install
npm run dev
```

## Структура проекта

Проект организован по методологии **Feature-Sliced Design (FSD)**.

Основные слои:

```
src/
├── app
├── pages
├── widgets
├── features
├── entities
└── shared
```

## Примечание

Данные представлены в виде моков. Логика записи и оплаты, согласно условиям задания, не реализована.
